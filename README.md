# rozbir, an RPM Spec parser library for Haskell

розбір is Ukrainian for "parsing."

this is intended to parse and lint RPM Spec files for Haskell projects. namely, i wanted this to simplify [oglyad](https://github.com/terrapkg/oglyad).
